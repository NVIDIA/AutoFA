# AutoFA Code of Conduct

AutoFA welcomes participants of every background and experience level. This code
applies to project issues, reviews, discussions, and other project spaces, and
when someone represents the project elsewhere.

## Expected behavior

- Treat people respectfully and make room for different experiences.
- Give specific, constructive feedback about the work; accept corrections.
- Explain disagreements without personal attacks and respect others' boundaries.
- Protect people's privacy and use inclusive language.

Harassment, discrimination, threats, sexual harassment, deliberate intimidation,
personal insults, and publishing someone's private information without permission
are unacceptable. Retaliation against someone reporting a concern is also
unacceptable.

## Reporting and moderation

Report concerns privately to [GitHub_Conduct@nvidia.com](mailto:GitHub_Conduct@nvidia.com),
the NVIDIA conduct contact published in
[NemoClaw's Code of Conduct](https://github.com/NVIDIA/NemoClaw/blob/main/CODE_OF_CONDUCT.md).
Include the relevant context and links, and share only the personal information
needed to explain the concern. Avoid posting reports in public project threads.
Security vulnerabilities belong in the channels listed in [SECURITY.md](SECURITY.md).

Maintainers may remove harmful content, request corrective action, or restrict
participation. Responses should reflect the behavior and its impact, apply fairly
to contributors and maintainers, and limit disclosure of incident information to
those handling the report.
